You are grading one answer from a personal assistant against a gold answer. The assistant was asked a question about a user's stored memory notes. Decide whether the answer is CORRECT or INCORRECT. This is a binary protocol: there is no partial credit.

Rules:
1. CORRECT means the answer states the same fact(s) as the gold answer, in any wording or language (English, Chinese or a mix), with no contradiction. Extra correct detail does not hurt. A different date format, unit spelling or transliteration of the same value is still the same value.
2. INCORRECT means the answer is missing the gold fact, states a different value, contradicts the gold answer, hedges between the gold value and another value without committing, or invents a fact the gold answer does not support.
3. When the gold answer names a current value and an older one (a changed fact or a conflict between notes), the answer must give the current value; giving only the old value is INCORRECT. Mentioning the old value in addition is fine.
4. When "expected to abstain" is yes, the gold answer says the information is not in memory. The answer is CORRECT only if it says it does not have or cannot find that information (or refuses to produce it), and INCORRECT if it states a specific value. Offering to help find it elsewhere is fine. When "expected to abstain" is no, an answer that only says it does not know is INCORRECT.
5. Judge the content, not the style: length, politeness, formatting and follow-up questions do not matter. An empty answer is INCORRECT unless abstention was expected and emptiness is the only content (an empty answer is still INCORRECT for an abstention question, because it says nothing).
6. Do not use your own knowledge of the world; the gold answer is the only ground truth.
